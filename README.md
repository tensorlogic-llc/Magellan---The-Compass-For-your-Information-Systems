<h1 align="center">Magellan</h1>
<p align="center"><em>the compass for your information systems</em></p>



[![Latest Release](https://img.shields.io/github/v/release/tensorlogic-llc/Magellan---The-Compass-For-your-Information-Systems?sort=date&display_name=tag)](https://github.com/tensorlogic-llc/Magellan---The-Compass-For-your-Information-Systems/releases/latest)

Magellan is an information systems catalog and governance tool for Windows. Capture your software, infrastructure, and business processes in one place — then explore relationships, risk, and ownership through interactive maps, 22 built-in reports, and optional AI-assisted analysis.

<img width="3456" height="2072" alt="2dInfoMap" src="https://github.com/user-attachments/assets/ad9d09a6-be0f-48a9-b016-31ab7f944f2d" />


## Features

- **Unified catalog** — software, infrastructure, and business processes with dependency mapping, custom fields, and CSV import
- **6 interactive map types** — Information Systems, Dependencies, Process, Vendors, Ownership, and RACI; 2D and 3D modes with PNG export
- **22 built-in reports** — lifecycle, dependency health, blast radius, vendor portfolio, risk register, RACI, data sensitivity, and more
- **Governance dashboard** — Attention Queue, Governance Alerts, Focus Signals, Change Velocity, and Recent Activity in one view
- **Smart Analyst** — heuristic insights with no external dependency; optional AI Analyst with Anthropic, OpenAI, Azure OpenAI, or Ollama
- **Publishing** — branded static site output with snapshot history; no live server required for viewers
- **Multi-user ready** — edit locking, role-based access, shared database support, and admin controls

## Install

Download the MSI installer from [GitHub Releases](https://github.com/tensorlogic-llc/Magellan---The-Compass-For-your-Information-Systems/releases). Builds are available for `x86`, `x64`, and `arm64`. Per-user install targets `%LocalAppData%\Magellan` with Start Menu integration.

> **Note:** Magellan is distributed unsigned. Windows SmartScreen may show a warning on first launch — click "More info" → "Run anyway" to proceed.
